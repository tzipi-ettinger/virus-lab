# virus-lab

מנוע שקורא טפסי התחייבות (סרוקים, מצולמים וכתובים ביד) של המעבדה המרכזית לנגיפים, מחלץ את השדות, מסמן שדות שדורשים בדיקה, ומייצא לאקסל.

פרויקט להאקתון AI קוד פתוח 2026.

## מבנה

```
virus-lab/
├── backend/    # Python + FastAPI: קליטת קבצים, חילוץ עם Gemini, נרמול, ולידציה, ייצוא Excel
└── frontend/   # React + TypeScript + Vite: העלאה, תצוגה מקדימה, טבלת תוצאות, עריכה
```

הוראות הרצה מפורטות נמצאות ב-README של כל תיקייה.

## כללי עבודה

- עובדים ב-feature branches (`feature/<name>`), ממזגים ל-`main` רק דרך Pull Request אחרי בדיקה.
- קבצי `.env` אמיתיים לא נכנסים ל-Git. משתמשים ב-`.env.example` כתבנית.
- לא מעלים מסמכים של מטופלים אמיתיים. עובדים רק עם טפסי הדוגמה של האתגר.
