# backend

Python 3.13 + FastAPI + PostgreSQL. קריאת העמודים עם Gemini, כללים ונרמול, שמירת רשומות, אישור, חיפוש וייצוא CSV/JSON. בשרת החי הוא גם מגיש את ה־frontend הבנוי.

| תיקייה | מה יש בה |
|---|---|
| `app/api/` | הנתיבים: כניסה, העלאה וקריאה, רשומות, תמונת עמוד, בריאות |
| `app/pipeline/` | קליטת קבצים, תיקון כיוון, קריאת שם מחיתוך מוגדל, צירוף עמודי המשך, הרכבת הטופס |
| `app/extraction/` | ספקי ה־AI (Gemini, מדומה, מטמון) וה־prompts |
| `app/rules/` | נרמול, ולידציה, מדיניות בדיקה, רשימה סגורה של גורמים שולחים |
| `app/storage/` | המסד: סכמה, שאילתות, תיקון ואישור |
| `app/auth/` | סיסמאות (`scrypt`) וסשנים |
| `app/export/` | ייצוא CSV ו־JSON |
| `eval/` | טבלת האמת והמדידה מולה |
| `scripts/` | יצירת משתמש, נתוני הדגמה, מחיקת נתונים, ייצוא OpenAPI |

התקנה, הרצה, משתני סביבה ובדיקות: [README הראשי](../README.md#התקנה-והרצה). האיפיון והחוזה: [docs/SPEC.md](../docs/SPEC.md).
